GPU bilinear resize. When you need nearest-neighbor or other interpolation semantics, use the CPU `opencv_resize`.

**Module**：GPU image processing · **Task type**：`gpu_resize`


## Ports

**Inputs**

| Port | Type | Required |
|---|---|---|
| `in` | Image / cv::Mat | ✓ |

**Outputs**

| Port | Type | Required |
|---|---|---|
| `out` | `task_graph::Image` | ✓ |

## Parameters

| 参数 | 类型 | 默认值 | 范围 / 选项 | 说明 |
|---|---|---|---|---|
| `target_w` | int | `256` | [1, 16384] |  |
| `target_h` | int | `256` | [1, 16384] |  |
