Gamma correction via LUT. `gamma` < 1 lifts shadows, > 1 darkens; linear→sRGB conversion (and back) is the same node.

**Module**：OpenCV enhancement · **Task type**：`opencv_gamma_correct`


## Ports

**Inputs**

| Port | Type | Required |
|---|---|---|
| `in` | Image / cv::Mat | ✓ |

**Outputs**

| Port | Type | Required |
|---|---|---|
| `out` | `cv::Mat` | ✓ |

## Parameters

| 参数 | 类型 | 默认值 | 范围 / 选项 | 说明 |
|---|---|---|---|---|
| `gamma` | float | `1` | [0.01, 10] | exponent; ~0.45 for linear→sRGB |
