GPU gamma (computed directly as a power on the GPU), semantics of `opencv_gamma_correct`.

**Module**：GPU image processing · **Task type**：`gpu_gamma`


## Ports

**Inputs**

| Port | Type | Required |
|---|---|---|
| `in` | Image / cv::Mat | ✓ |

**Outputs**

| Port | Type | Required |
|---|---|---|
| `out` | `task_graph::Image` | ✓ |

## Parameters

| 参数 | 类型 | 默认值 | 范围 / 选项 | 说明 |
|---|---|---|---|---|
| `gamma` | float | `1` | [0.1, 5] |  |
