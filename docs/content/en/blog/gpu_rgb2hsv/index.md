GPU RGB→HSV. Note the GPU output normalizes hue to [0,1] (OpenCV 8-bit images use 0-179), so downstream comparison thresholds must be scaled accordingly.

**Module**：GPU image processing · **Task type**：`gpu_rgb2hsv`


## Ports

**Inputs**

| Port | Type | Required |
|---|---|---|
| `in` | Image / cv::Mat | ✓ |

**Outputs**

| Port | Type | Required |
|---|---|---|
| `out` | `task_graph::Image` | ✓ |
